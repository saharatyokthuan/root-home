# ฟินานซ์ส่วนตัว — Personal Finance Tracker

แอปบันทึกรายรับ-รายจ่ายส่วนตัว ทำงานบนเบราว์เซอร์ ติดตั้งบนมือถือได้ ใช้งานออฟไลน์ได้ เก็บข้อมูลในเครื่อง (localStorage) ไม่ส่งขึ้นเซิร์ฟเวอร์

🔗 **ใช้งานออนไลน์:** https://saharatyokthuan.github.io/personal-finance/

## คุณสมบัติ

- บันทึกรายรับและรายจ่าย พร้อมหมวดหมู่ วันที่ จำนวนเงิน หมายเหตุ
- ดูสรุปยอดเดือน (รายรับเดือนนี้, รายจ่ายเดือนนี้, ยอดคงเหลือ)
- ดูรายการทั้งหมดและกรองตามเดือน
- จัดการหมวดหมู่รายรับและรายจ่าย
- สำรองข้อมูลเป็นไฟล์ JSON / กู้คืนจากไฟล์
- เก็บข้อมูลในเครื่องเท่านั้น การล้างข้อมูลเบราว์เซอร์จะลบข้อมูลทั้งหมด

## วิธีใช้งาน

1. เปิดไฟล์ `index.html` ในเบราว์เซอร์
2. หรือผ่าน local server:
   ```bash
   python3 -m http.server 8000
   ```
   แล้วเปิด http://localhost:8000
3. ติดตั้งบนมือถือ: เปิดในเบราว์เซอร์แล้วเลือก "เพิ่มไปยังหน้าจอหลัก" (Add to Home Screen)

## โครงสร้างไฟล์

- `index.html` — หน้าแรก สรุปยอดเดือน
- `transactions.html` — หน้ารายการทั้งหมด
- `categories.html` — หน้าจัดการหมวดหมู่
- `settings.html` — หน้าตั้งค่า สำรองและกู้คืนข้อมูล
- `css/style.css` — ธีมสีและเลย์เอาต์
- `js/utils.js` — ฟังก์ชันช่วย (วันที่, รูปแบบเงิน, escapeHTML)
- `js/db.js` — ชั้นข้อมูล localStorage
- `js/nav.js` — การนำทางระหว่างหน้า
- `js/index.js` — logique หน้าแรก
- `js/transactions.js` — logique หน้ารายการทั้งหมด
- `js/categories.js` — logique หน้าหมวดหมู่
- `js/settings.js` — logique หน้าตั้งค่า
- `manifest.json` — ไฟล์กำหนด PWA
- `sw.js` — Service Worker สำหรับใช้งานออฟไลน์

## การเก็บข้อมูล

ข้อมูลทั้งหมดเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้นเท่านั้น การล้างข้อมูลเบราว์เซอร์จะลบข้อมูลทั้งหมด โปรดสำรองข้อมูลเป็นไฟล์ JSON เป็นประจำที่หน้าตั้งค่า

## เทคโนโลยี

HTML5, CSS3, Vanilla JavaScript (ไม่มีเฟรมเวิร์ก, ไม่มี build step, ไม่มี package manager)
