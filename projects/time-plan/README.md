# แผนเวลา — Time Plan PWA

แอปวางแผนออกกำลังกายรายวัน ทำงานบนเบราว์เซอร์ ติดตั้งบนมือถือได้ ใช้งานออฟไลน์ได้

## คุณสมบัติ

- ตั้งค่าเป้าหมายออกกำลังกายต่อวัน (นาที)
- ดูช่วงเวลาว่างและจองช่วงเวลาออกกำลังกายก่อนกิจกรรมอื่น
- ป้องกันการจองช่วงเวลาทับซ้อนกัน
- ทำเครื่องหมายว่าเสร็จแล้ว และนับสตรีคต่อเนื่อง
- เก็บข้อมูลในเครื่อง (localStorage) ไม่ส่งขึ้นเซิร์ฟเวอร์

## วิธีใช้งาน

1. เปิดไฟล์ `index.html` ในเบราว์เซอร์
2. หรือผ่าน local server:
   ```bash
   python3 -m http.server 8000
   ```
   แล้วเปิด http://localhost:8000
3. ติดตั้งบนมือถือ: เปิดในเบราว์เซอร์แล้วเลือก "เพิ่มไปยังหน้าจอหลัก" (Add to Home Screen)

## โครงสร้างไฟล์

- `index.html` — หน้าเดียว มีทุก section
- `css/style.css` — ธีมสีและเลย์เอาต์
- `js/app.js` — ตรรกะทั้งหมด: ข้อมูล, แสดงผล, เหตุการณ์
- `manifest.json` — ไฟล์กำหนด PWA
- `sw.js` — Service Worker สำหรับใช้งานออฟไลน์

## การเก็บข้อมูล

ข้อมูลทั้งหมดเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้นเท่านั้น การล้างข้อมูลเบราว์เซอร์จะลบข้อมูลทั้งหมด

## การทดสอบ

รันทดสอบทั้งหมด (จำลองสภาพแวดล้อมเบราว์เซอร์ใน Node):

```bash
cd projects/time-plan
node test/run.js
```

หรือรันทีละไฟล์:

```bash
node test/01-today-str.test.js
node test/07-overlap.test.js
```

## การยืนยันออฟไลน์ (PWA)

1. เปิดผ่าน local server: `python3 -m http.server 8000` แล้วเปิด `http://localhost:8000/projects/time-plan/index.html`
2. เปิด DevTools → Application → Service Workers ตรวจว่า `sw.js` ทำงานอยู่
3. ปิดเครือข่าย (Offline) แล้วโหลดหน้าใหม่ แอปควรยังแสดงผลจากแคชได้
4. ติดตั้งบนมือถือ: เปิดใน Chrome แล้วเลือก "เพิ่มไปยังหน้าจอหลัก" (Add to Home Screen)
